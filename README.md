# QUINN Wash & Dry · ระบบร้านซักผ้า

ระบบบันทึกรายรับ-รายจ่ายร้านซักผ้า สะสมแต้มลูกค้า ออกใบเสร็จพร้อม QR ให้ลูกค้าเช็คแต้มเอง
ใช้ **GitHub Pages** เป็นที่วางหน้าเว็บ และ **Firebase** (ของ Google) เป็นฐานข้อมูลกับระบบล็อกอิน ใช้ฟรีทั้งคู่สำหรับร้านขนาดนี้

## ไฟล์ในชุดนี้

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `index.html` | ระบบหลัก: หน้าล็อกอิน · หน้าร้าน (พนักงาน) · หลังบ้าน (เจ้าของ) · หน้าบ้านให้ลูกค้ากดสะสมแต้ม |
| `check.html` | หน้าที่ลูกค้าเห็นเมื่อสแกน QR บนใบเสร็จ: แต้มล่าสุด วันที่มาใช้บริการ ยอดสะสม |
| `config.js` | ค่าเชื่อมต่อ Firebase (ต้องแก้ 1 ครั้ง ในขั้นตอนที่ 4) |
| `firestore.rules` | กฎความปลอดภัยของฐานข้อมูล (วางใน Firebase ในขั้นตอนที่ 3) |
| `img/` | โลโก้และภาพน้องแมวของร้าน (logo, welcome, tablet, reward, money, thanks) |

> ถ้ายังไม่ได้ใส่ค่าใน `config.js` เว็บจะเปิดใน **โหมดทดลอง** ใช้งานได้ครบแต่เก็บข้อมูลไว้ในเบราว์เซอร์เครื่องนั้นเท่านั้น และไม่มีหน้าล็อกอิน เหมาะไว้ลองกดดูก่อน

## ขั้นตอนติดตั้ง (ทำครั้งเดียว ประมาณ 20–30 นาที)

### 1. เอาไฟล์ขึ้น GitHub
1. สมัคร/ล็อกอิน https://github.com
2. กดปุ่ม **New** (สร้าง repository) ตั้งชื่อ เช่น `laundry` เลือก **Public** แล้วกด **Create repository**
3. กด **uploading an existing file** แล้วลากไฟล์ทั้งหมดในโฟลเดอร์นี้ **รวมทั้งโฟลเดอร์ `img`** ลงไป (ลากทั้งโฟลเดอร์ได้เลย) กด **Commit changes**
   - ตรวจว่าในหน้า repository เห็นโฟลเดอร์ `img` อยู่ ไม่อย่างนั้นโลโก้และรูปแมวจะไม่ขึ้น

### 2. เปิดหน้าเว็บด้วย GitHub Pages
1. ใน repository กด **Settings** > เมนูซ้าย **Pages**
2. ช่อง **Source** เลือก **Deploy from a branch** · Branch เลือก **main** และ **/ (root)** กด **Save**
3. รอ 1–2 นาที จะได้ที่อยู่เว็บ เช่น `https://ชื่อผู้ใช้.github.io/laundry/` (จดไว้)

### 3. สร้าง Firebase
1. ไปที่ https://console.firebase.google.com ล็อกอินด้วยบัญชี Google แล้วกด **Create a project** (ปิด Google Analytics ได้)
2. **เปิดระบบล็อกอิน:** เมนูซ้าย **Build > Authentication** > **Get started** > เลือก **Email/Password** > เปิด **Enable** > **Save**
3. ในหน้า Authentication แท็บ **Settings > Authorized domains** กด **Add domain** ใส่ `ชื่อผู้ใช้.github.io` (ไม่ต้องมี https:// และไม่ต้องมีชื่อ repository)
4. **สร้างฐานข้อมูล:** เมนูซ้าย **Build > Firestore Database** > **Create database** > เลือก location **asia-southeast1 (Singapore)** > เลือก **Start in production mode** > **Create**
5. **ใส่กฎความปลอดภัย:** ในหน้า Firestore แท็บ **Rules** ลบข้อความเดิมทั้งหมด แล้วคัดลอกทุกบรรทัดจากไฟล์ `firestore.rules` ไปวาง กด **Publish**

### 4. เชื่อมเว็บกับ Firebase
1. ใน Firebase กดรูปเฟือง ⚙️ (ข้าง Project Overview) > **Project settings**
2. เลื่อนลงไปที่ **Your apps** กดไอคอน **`</>`** (Web) ตั้งชื่อแอป เช่น `laundry-web` > **Register app**
3. จะเห็นโค้ด `const firebaseConfig = { apiKey: "...", ... }` ให้คัดลอกค่าแต่ละบรรทัด
4. กลับไปที่ GitHub เปิดไฟล์ `config.js` กดรูปดินสอ ✏️ แล้วแทนที่ข้อความ `ใส่ apiKey`, `ใส่ authDomain` ฯลฯ ด้วยค่าที่คัดลอกมา กด **Commit changes**
5. รอ 1–2 นาทีให้ GitHub Pages อัปเดต

### 5. สร้างบัญชีเจ้าของร้าน
1. เปิดที่อยู่เว็บจากขั้นตอนที่ 2
2. ครั้งแรกจะขึ้นหน้า **ตั้งค่าครั้งแรก: สร้างบัญชีเจ้าของร้าน** ใส่ชื่อร้าน ชื่อเจ้าของ **อีเมลจริงของเจ้าของ** (แนะนำ เพื่อใช้รีเซ็ตรหัสผ่านได้) และรหัสผ่าน
3. กดสร้าง ระบบจะเข้าหลังบ้านให้ทันที หน้านี้จะไม่ขึ้นอีก

### 6. ตั้งค่าร้านและสร้างบัญชีพนักงาน
ที่หลังบ้าน แท็บ **ตั้งค่า**:
- **ร้านและใบเสร็จ:** ชื่อร้าน LINE ID ร้าน ขนาดกระดาษ (58 หรือ 80 มม.) ข้อความท้ายใบเสร็จ
- **แต้มสะสม:** รางวัล แต้มที่ใช้ มูลค่าที่ลดได้ และจำนวนวันที่ต้องแลก
- **บัญชีพนักงาน:** ใส่ชื่อพนักงาน ชื่อผู้ใช้ (ภาษาอังกฤษ เช่น `khin`) รหัสผ่าน อย่างน้อย 6 ตัว แล้วกด **สร้างบัญชีพนักงาน**
- **หน้าบ้าน:** รหัสออกจากหน้าบ้าน (กันลูกค้ากดออก)
- กด **บันทึกการตั้งค่า** ด้านล่างสุด

พนักงานเปิดเว็บเดียวกัน แล้วล็อกอินด้วยชื่อผู้ใช้กับรหัสผ่านของตัวเอง จะเห็นเฉพาะ **หน้าร้าน**

## การใช้งานประจำวัน

**พนักงาน (หน้าร้าน)**
- พิมพ์เบอร์ลูกค้า ใส่จำนวนถังซัก/อบ ยอดเงิน แล้วกด **บันทึกลูกค้า** ระบบจะสะสมแต้มและเปิดใบเสร็จให้ทันที
- เบอร์ใหม่ ระบบสมัครสมาชิกให้อัตโนมัติ
- แต้มครบ จะมีปุ่ม **แลกแต้ม**
- **ขายน้ำยา:** กด + ทุกครั้งที่ขายได้ 1 ซอง
- ใบเสร็จย้อนหลัง: กดไอคอนใบเสร็จท้ายแถวในตารางลูกค้า

**เจ้าของ (หลังบ้าน)**
- นับเหรียญจากตู้ซัก+ตู้อบ ยอดสแกนจ่าย เงินในตู้แลกเหรียญ เงินสำรอง ค่าใช้จ่าย แล้วกด **บันทึกเงินสิ้นวัน**
- ดูสมาชิก สรุปเดือน และดาวน์โหลด Excel ได้

## ใบเสร็จและการปริ้น
- ปุ่ม **ปริ้น** ใช้หน้าต่างปริ้นของเบราว์เซอร์ ใช้ได้กับเครื่องปริ้นที่มือถือ/คอมมองเห็น
- ปุ่ม **บันทึกรูป** ได้ไฟล์รูปใบเสร็จ ขนาดพอดีกระดาษความร้อน
  - **เครื่องปริ้นความร้อนบลูทูธ (Android):** ติดตั้งแอป **RawBT** หรือแอปของยี่ห้อเครื่องปริ้น แล้วแชร์รูปใบเสร็จไปที่แอปนั้นเพื่อปริ้น
  - หรือส่งรูปให้ลูกค้าทางไลน์แทนการปริ้น
- **QR บนใบเสร็จ:** ลูกค้าสแกนด้วยกล้องมือถือ จะเปิดหน้า `check.html` เห็นแต้มล่าสุด วันที่มาใช้บริการ จำนวนครั้ง และยอดสะสม ใช้ได้ตลอด แต้มอัปเดตทุกครั้งที่มาใช้บริการ (QR ใช้รหัสสุ่ม ไม่มีเบอร์โทรอยู่ในลิงก์)

## ปัญหาที่พบบ่อย
- **ขึ้นว่า "โหมดทดลอง":** ยังไม่ได้ใส่ค่าใน `config.js` หรือ GitHub ยังไม่อัปเดต รอ 1–2 นาทีแล้วรีเฟรช
- **ล็อกอินแล้วขึ้น error เกี่ยวกับ domain:** ยังไม่ได้เพิ่ม `ชื่อผู้ใช้.github.io` ใน Authorized domains (ขั้นตอนที่ 3.3)
- **ขึ้นว่า "บัญชีนี้ยังไม่มีสิทธิ์ใช้งาน":** บัญชีนั้นถูกปิด หรือไม่ได้สร้างจากหน้า ตั้งค่า > บัญชีพนักงาน
- **พนักงานลืมรหัสผ่าน:** เจ้าของกด ✕ ปิดบัญชีเดิมในหน้าตั้งค่า แล้วสร้างบัญชีใหม่ด้วยชื่อผู้ใช้ใหม่
- **เจ้าของลืมรหัสผ่าน:** ที่หน้าล็อกอิน พิมพ์อีเมลแล้วกด **ลืมรหัสผ่าน** ระบบจะส่งลิงก์ตั้งรหัสใหม่ไปที่อีเมล

## เรื่องความปลอดภัย
- ค่าใน `config.js` เปิดเผยได้ เป็นเรื่องปกติของ Firebase ความปลอดภัยอยู่ที่ไฟล์ `firestore.rules`
- พนักงานอ่านข้อมูลเงินสิ้นวัน เงินสำรอง และค่าใช้จ่ายไม่ได้ (ถูกกันไว้ที่ฐานข้อมูล ไม่ใช่แค่ซ่อนบนหน้าจอ)
- ลูกค้าเห็นได้เฉพาะหน้าแต้มของตัวเองผ่าน QR เท่านั้น
- แพ็กเกจฟรีของ Firebase (Spark) อ่านได้ 50,000 ครั้ง/วัน และเขียน 20,000 ครั้ง/วัน เพียงพอสำหรับร้านซักผ้าทั่วไป

## เปลี่ยนรูปภาพ
ภาพทั้งหมดอยู่ในโฟลเดอร์ `img` ถ้าจะเปลี่ยน ให้อัปโหลดไฟล์ใหม่ทับโดยใช้ **ชื่อไฟล์เดิม**
- `logo.webp` โลโก้ร้าน (หัวเว็บ หน้าล็อกอิน หน้าบ้าน หน้าเช็คแต้ม และหัวใบเสร็จแบบขาวดำ)
- `welcome.webp` หน้าล็อกอิน
- `tablet.webp` หน้าบ้าน ตอนให้ลูกค้ากดเบอร์
- `reward.webp` เมื่อแต้มครบพร้อมแลก
- `money.webp` สรุปเงินของวันในหลังบ้าน
- `thanks.webp` หน้าขอบคุณหลังสะสมแต้ม และท้ายหน้าเช็คแต้ม
